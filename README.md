# Музыка на шаговых двигателях

Электромеханический музыкальный инструмент: шесть шаговых двигателей воспроизводят разные партии мелодии. Звук создают сами моторы своей вибрацией, без каких-либо динамиков.

Управлять инструментом можно через MusicMotorStudio на компьютере, с USB-MIDI-инструмента или с сенсорного дисплея. Мелодии сохраняются в памяти устройства для автономного воспроизведения.

## Возможности

- Воспроизведение MIDI на шести независимых моторах.
- Живая игра с USB-MIDI-инструмента.
- Автоматическое распределение нот с учётом мелодии, аккордов и Sustain.
- Ручное закрепление нот за моторами.
- Хранение до десяти мелодий в памяти устройства.
- Выбор мелодии, запуск, пауза и перемотка с дисплея.
- Ручное управление моторами по ноте или частоте.
- Индикация состояния моторов и подключения USB/MIDI.
- Общая кнопка остановки всех моторов.

## Как устроен инструмент

Частота импульсов STEP задаёт высоту ноты, а длительность движения — её продолжительность. Несколько моторов одновременно воспроизводят мелодию и аккомпанемент.

**STM32F103** формирует импульсы STEP аппаратными таймерами и управляет шестью моторами через драйверы STEP/DIR.

**ESP32-S3** обслуживает сенсорный дисплей, USB-MIDI и хранилище мелодий.

**MusicMotorStudio** загружает MIDI, распределяет ноты по моторам и управляет воспроизведением с компьютера.

Платы связаны однопроводным UART: GPIO4 ESP32 — PA2 STM32, общий GND, скорость 230400 бод.

## MusicMotorStudio

Приложение для Windows позволяет:

- открывать и редактировать MIDI;
- настраивать партии, темп, транспонирование и громкость нот;
- распределять ноты между моторами автоматически и вручную;
- прослушивать результат на компьютере;
- сохранять MIDI и проекты;
- экспортировать сыгранные моторные партии;
- преобразовывать аудио в ноты;
- управлять устройством и записывать мелодии в его память.

### Запуск

Скачайте **MusicMotorStudio.exe** из [релизов](https://github.com/Coal56AB/music_motor/releases) и запустите. Приложение собрано через Nuitka для Windows x64; установка Python не требуется.

Подключите STM32 к компьютеру, выберите COM-порт и нажмите **«Подключиться»**. Откройте MIDI, настройте распределение нот и запустите воспроизведение.

Для автономной работы нажмите **«Сохранить в устройство»** во вкладке **«Воспроизведение»**, выбрав одно из десяти мест.

### Редактирование MIDI

Стратегия **«Аккорды, мелодия и Sustain»** учитывает музыкальные линии, аккорды и ноты, удерживаемые педалью. Исходные ноты и MIDI-контроллеры сохраняются. Сыгранные участки окрашены в цвет мотора, несыгранные показаны серым.

Чтобы закрепить ноты за мотором, выделите их, выберите мотор и нажмите **«Применить к выделенным нотам»**. После правок нажмите **«Пересчитать распределение»**. Пересечения несовместимых закреплений отмечаются как конфликты. Доступны Undo/Redo.

**«Сохранить MIDI»** сохраняет исходные ноты и контроллеры. **«Экспорт для моторов»** сохраняет только сыгранные участки. **«Сохранить проект»** сохраняет редакторские партии и ручные закрепления.

В базовую сборку входит спектральное распознавание аудио. Дополнительные движки librosa pYIN и Basic Pitch в неё не входят.

## Управление с дисплея

Выберите сохранённую композицию во вкладке **«Мелодия»**, затем нажмите **«Пуск»** во вкладке **«Обзор»**. Кнопки выбора пропускают пустые места, шкала воспроизведения позволяет перематывать мелодию.

В ручном режиме мотору можно задать ноту или частоту:

- **Нота:** кнопки «− / +» изменяют высоту на полутон; нажатие на поле открывает выбор ноты, диеза и октавы. Диапазон — E0–B7.
- **Частота:** ввод значения в герцах, шаг кнопок — 10 Гц.

Кнопка **«СТОП ВСЁ»** останавливает все моторы.

## Структура проекта

- `firmware/` — прошивка STM32, конфигурация CubeMX и проект Keil.
- `esp32-diplsay-midi/` — подмодуль с прошивкой ESP32 и интерфейсом дисплея.
- `desktop/` — исходники MusicMotorStudio.
- `desktop/tests/` — автоматические проверки.
- `docs/` — документация и изображения.
- `Запустить.cmd` — запуск MusicMotorStudio из исходников.

## Сборка из исходников

Клонирование вместе с подмодулем:

```bash
git clone --recurse-submodules https://github.com/Coal56AB/music_motor.git
```

### MusicMotorStudio

Для запуска из исходников используется Python 3.7 x64:

```powershell
py -3.7 -m pip install -r desktop/requirements.txt
py -3.7 desktop/run.py
```

Также можно использовать `Запустить.cmd`.

Для сборки автономного `.exe` нужны MSVC и Nuitka:

```powershell
py -3.7 -m pip install Nuitka==2.7.12
py -3.7 desktop/build_nuitka.py
```

Результат: `_service/build/nuitka/MusicMotorStudio.exe`.

### STM32

Откройте `firmware/MDK-ARM/MusicMotor.uvprojx` в Keil, соберите проект и прошейте контроллер.

Готовый HEX: `firmware/MusicMotor.hex`.

### ESP32

Откройте `esp32-diplsay-midi/Firmware/ESP32` в VS Code с PlatformIO, выберите окружение `display` и выполните **Upload**.

## Проверки

```powershell
py -3.7 -m unittest discover -s desktop/tests -v
```

Описание проверок и сборки тестовых модулей: [desktop/tests/README.md](desktop/tests/README.md).

# Композиции

В студии откройте «MIDI-редактор → Композиции». По умолчанию используется папка Songs рядом с EXE (при запуске из исходников — в корне репозитория). «Выбрать папку…» меняет папку поиска и сохраняет выбор.

Список обновляется при каждом открытии меню. Поддерживаются .mid, .midi и .motor.json, включая подпапки. Если MIDI и одноимённый проект лежат рядом, показывается проект с сохранёнными закреплениями за моторами. Открытие композиции включает полифонию 6 и стабильное распределение.

Встроенный пример Clockwise доступен отдельно через «Примеры». Остальные композиции не упаковываются в EXE: папку Songs можно дополнять без пересборки программы.

[Источники и описания аранжировок](SOURCES.md). В sources находятся исходные MIDI, доступные в меню с соответствующим путём.
